SEO RANK WATCH

CHICS ／ chics.top ／ 2026-09-10 開始

SEO順位ウォッチとは

新しく記事を作るのではなく、すでにある記事の検索順位を実測して、1本ずつ直して育てていく仕組みです。週1回、自動で動きます。

なぜやるのか

chics.topには400本以上の記事がありますが、これまで公開したあとに順位を測って直す工程がありませんでした。作りっぱなしの状態です。

Search Console（Googleの検索データ）を見ると、「1ページ目に入っているのにクリックされていない記事」がいくつもありました。あと少し直せば成果が出るものが、放置されたままになっている状態です。

新しく作るより、すでに評価されている記事を拾って伸ばすほうが早い。これがこの仕組みの狙いです。

進め方

  1. 順位を測る Search Console APIから、キーワードごとの順位・表示回数・クリック数を取得します。
  2. 1本だけ選ぶ 順位の割にクリックされていない記事を洗い出し、その中から受注につながるキーワードを1つだけ選びます。表示回数が多くても、他社ロゴを見に来ているだけの検索や、デザイナー志望者向けの検索は選びません。
  3. 検索意図を調べる 実際にそのキーワードで検索し、上位ページと比べて何が足りないかを特定します。
  4. 1か所だけ直す タイトルなど、原因と判断した箇所だけを直します。まとめて何本も変えません。同時に複数変えると、何が効いたのか分からなくなるためです。
  5. 14日間そのままにする Googleが変更を評価に反映するまで2〜4週かかります。この期間はその記事に一切触りません。
  6. 実測で判定して、次の1本へ 14日後に順位を測り直し、上がった／変わらなかった／下がったを数字で判定します。下がっていた場合は元に戻します。

自動化の中身

毎週月曜7:00に、GitHub Actionsで自動実行されます。順位の取得から、判定、記事の修正、記録、LINE通知まで一通り自動です。判断部分はAI（Claude）が担当しています。

自動で変更する範囲

  • 記事タイトル
  • meta description
  • 効果が出なかった場合の差し戻し

自動では変更しない範囲

  • 本文・見出し
  • URL・パーマリンク
  • 内部リンク構成
  • テーマ・プラグイン設定

本文をAIに自動生成させることは意図的にしていません。事実と違う内容が自動で増えていくリスクがあるためです。

ただし「本文は今後も一切触らない」という意味ではありません。順位が低い記事は、タイトルを直しても上がりません。その場合の原因は本文の情報量や検索意図とのズレなので、本文の改善が必要になります。そのケースは自動では行わず、クレーター側で内容を確認してから対応し、実施後にお知らせします。

コーダーさんへのお願い

観察期間中（14日間）の記事は触らないでください

現在どの記事が観察期間中かは、下のダッシュボードで確認できます。同じ期間に別の変更が入ると、効果の判定ができなくなります。

記事の追加・他の記事の修正は、これまで通り進めていただいて問題ありません。止めていただきたいのは「観察中と表示されている記事」だけです。

また、この仕組みは記事タイトルを書き換えます。タイトルが変わっていても、意図した変更です。変更内容と理由はすべてダッシュボードに記録されています。

技術メモ

順位データの取得
Google Search Console API。読み取り専用のサービスアカウント analytics-reader@crater-dashboard.iam.gserviceaccount.com を sc-domain:chics.top に「制限付き」で追加しています。既存のGA4ダッシュボードと同じアカウントの流用です。
記事の更新
WordPress REST API。記事はカスタム投稿タイプ news なので、エンドポイントは /wp-json/wp/v2/news/<ID> です（posts では404）。認証はアプリケーションパスワード。
WAFによる403について
サーバー側のWAFが、外部IP（GitHub Actions）からの /wp-json/ へのPOSTを403で弾いていました。現在は403を検知したら ?rest_route= のクエリ形式で自動的に再試行する実装で回避しています。WAF設定の変更はしていません。もし今後この挙動を調整される場合はご一報ください。
実行環境
GitHub Actions（.github/workflows/SEO順位ウォッチ.yml）。毎週月曜7:00 JST。実行結果は同リポジトリにコミットされ、LINEにも通知されます。
