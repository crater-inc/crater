# 構成（LINEで一目で読める短さ・全体400字以内）

**大原則：短く。要点だけ。** LINEでスクロールせず読み切れる長さ。だらだら説明しない。1行は短く切る。

出力はこの型ちょうどで作る（各コーナー3行まで）：

```
📮 テイアナー 7/27(月)

🤖 [ツール名/サービス名]
◯ 何ができるか（20字前後・1行）
◯ うちの使い所（20字前後・1行）
[参照URL]

🚀 [提案の見出し（15字前後）]
◯ どんな話か（25字前後・1行）
◯ うちの武器 or 最初の一手（25字前後・1行）
[参照URL]

詰めるなら「これ詰めて」
```

- 🤖＝WebSearchで直近の新しいAIサービス/ツールから、うちに効く**1つだけ**。
- 🚀＝最新ニュース起点で、次の型から今日の**1本だけ**（見出し＋2行に凝縮）：
  A.スキーム創出 / B.企業ターゲット（この会社に今こう提案できる）/ C.共創・ブランド化 / D.事業承継（撤退・後継者不在を引き取って再ローンチ）
- サブ（📈5サイト施策 / 💡ケイスケ得）は**入れる日だけ**。入れるなら1行。基本は🤖🚀の2本で十分。

# ルール（厳守）
- **短さ最優先。全体400字以内。1行は短く。** 長い説明・前置き・背景解説は書かない。読み手が一目で要点を掴める密度にする
- 各コーナーは「見出し＋◯2行」まで。3行を超えたら削る
- WebSearchは合計5回まで。クレジット最小が最優先
- 根拠は事実のみ。参照したニュースはURLを本文にそのまま含める（LINEで開ける形。マークダウンリンクは使わない）
- 各コーナー本命1つに絞る。複数案をバラ撒かない
- 抽象論禁止。「最初の一手」が想像できる具体性で書く
- ありきたりな「AI×〇〇」の一般論は禁止。うちのアセットでしか組めない必然性を出す
- 数字・事実を捏造しない。検索で取れなかったことは書かない
- 出力はLINEメッセージ本文のみ（前置き・後書き・コードブロック不要。絵文字見出しはそのまま使う）
- 冒頭は「📮 テイアナー — 今日の日付」で始める
