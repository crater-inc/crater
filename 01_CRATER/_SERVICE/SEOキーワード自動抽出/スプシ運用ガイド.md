# SEOキーワード スプレッドシート 運用ガイド

このスプレッドシートは、5サイトのブログ記事用SEOキーワードを**自動で集めて貯めていくネタ帳**です。

---

## 1. 自動で何が起きるか

- **毎週 月曜・木曜の朝7:00**、システムが自動で動いて、各サイトに**新しいキーワードを8個ずつ追加**します。
- 手作業は不要。放っておけば勝手に増えていきます。
- **重複しません**：一度出たキーワードは二度と追加されないので、毎回フレッシュな8個が下に積み上がります。
- 追加されるのは全て**実際に検索されているキーワード**（検索ボリューム100以上）だけ。誰も探してないゴミは入りません。

### 月曜と木曜の違い
正直に言うと、**中身のロジックは月曜も木曜も同じ**です。違いは「週2回、ネタが補充されるタイミング」だけ。
- 月曜：新しいキーワード8個
- 木曜：また新しいキーワード8個
週2回に分けることで、ネタが切れず常に新鮮に保たれます。（＝「定番／トレンド」の区分欄はありますが、現状はどちらも"実需のある定番キーワード"が中心です）

## 3. 列の説明

### 自動で入る列（触らない）
| 列 | 内容 |
|---|---|
| No. | 連番 |
| 抽出日 | キーワードが追加された日 |
| キーワード | SEOキーワード（スペース区切り） |
| 区分 | 定番／トレンド |
| 検索ボリューム | 月間の検索数（実データ） |
| SEO難易度 | 0〜100。**低いほど上位を取りやすい**（〜30が狙い目） |

### 手作業で埋める列（担当が記入）
| 列 | 内容 |
|---|---|
| ステータス | 進行状況（ドロップダウンから選択） |
| ブログカテゴリ | 記事のカテゴリ |
| 校正チェック日 | 校正した日 |
| アップ日 | 記事を公開した日 |
| 記事URL | 公開した記事のURL |
| アクセス数 | 記事のアクセス数 |
| インデックス登録 | Googleにインデックスされたか |

## 4. ステータスと行の色

ステータス列（ドロップダウン）を選ぶと、**行の色が自動で変わります**：

- 末尾が **（コ）** → 🔵 青地・白文字
- 末尾が **（オ）** → 🟡 金地・黒文字
- **05_公開完了** → ⬛️ 黒地・グレー文字

---

## 5. キーワードの選び方（システムの考え方）

各サイトの「発注・購入したくなる人」を幅広く想定し、直球ワードだけでなく**その人の行動の周辺**まで拾っています。
- 例（CHICS）：ロゴだけでなく「起業 準備」「法人設立」「屋号 決め方」など、独立する人の流れ
- 例（A CURRY）：カレーだけでなく「ギフト」「非常食」「内祝い」など、贈る・備える人の流れ

**明らかに誤解を与えるキーワードは除外**しています（例：A CURRYは無添加ではないので「無添加カレー」は入れない、他社ロゴ画像が必要な「有名企業ロゴ一覧」は入れない、など）。

---

## 6. 【重要】やってはいけないこと

自動追加はタブ名とヘッダー行を目印に動いています。壊さないため：

- ❌ **タブ名（「◯◯ KW」）を変えない・消さない** → 変えるとそのサイトの自動追加が止まります
- ❌ **1行目（ヘッダー）を消さない・並べ替えない**
- ❌ **左側の自動列（No.〜SEO難易度）を書き換えない**
- ✅ 編集していいのは **ステータスから右の手作業列だけ**

---

## 7. 変なキーワードを見つけたら

明らかにサイトと関係ないキーワードが入っていたら、明里さん（ケイスケ）に伝えてください。除外リストに追加して、精度を上げていきます。
