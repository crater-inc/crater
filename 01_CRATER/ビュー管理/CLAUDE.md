# VIEW管理（view.crater.co.jp のページをまとめる大元のページ）

## これは何か
- 左にページ名（グループ分け）、押すと右にそのページが表示される社内用ページ。ケイスケさん用。
- 公開URL：https://view.crater.co.jp/01_CRATER/%E3%83%93%E3%83%A5%E3%83%BC%E7%AE%A1%E7%90%86/index.html （パスワード `fj`。打ちやすさ優先でケイスケさん指定）
- 方針：view上のページがメイン。「入れたいものだけ入れていく」スタイル。全部は入れない。

## ファイル
- `index.html`：画面本体。一覧の中身はここに書かない。
- `ページ一覧.js`：左に並ぶページの一覧。**追加・並べ替え・グループ分けはこのファイルだけを触る。**

## ページを追加するとき（「VIEW管理に入れて」「ビュー管理に追加して」等）
1. `ページ一覧.js` の該当グループに `{ アイコン: '📈', 名前: '…', URL: '/…' }` を1行足す（グループがなければかたまりごと足す）。
   - **アイコンは絵文字1つを、ページの内容からクロコが判断して必ず付ける**（2026-09-12 ケイスケさん指定）。既存：📈アクセス解析／🔍SEO／🏛️入札／💎ハイエンドEC／🤖AIタスク／🏢会社案内／🏠トップ。
   - URLは view のドメイン以降（`/01_CRATER/…`）。`https://view.crater.co.jp/…` のまま入れても動く。
2. 追加するページ自体がコミット・push済みか確認（未pushだと右側が404になる）。
3. `git add` はこのフォルダのファイルだけ → commit → push → View URLを返す（他セッションの変更を巻き込まない）。
4. そのページが新しい名前のパスワード記憶キー（`sessionStorage.setItem('〇〇', '1')`）を使っている場合は、`index.html` の「ページのパスワード記憶キー」にも足す（足さないと中でパスワードを聞かれる）。

## 仕様・確認済みの事実
- **タブのタイトルは必ず頭を「VIEW管理」にする**（開いたページに関係なく「VIEW管理 | ページ名」、何も開いていない時は「VIEW管理」）。2026-09-11 ケイスケさん指定「とにかく頭をVIEW管理で」。
- **右側に出すページは白背景が基本**（2026-09-11 ケイスケさん指定・今後も含めて）。黒系のページを入れるときは白に直す。自動生成のページは生成スクリプト側の色を直す（出力HTMLだけ直すと次の自動実行で戻る）。
- 右側は各プロジェクトのHTMLをそのまま読み込んでいる（VIEW管理用に作り直したものではない）。各ページを直せばVIEW管理にもそのまま反映される。
- view のページは右側に表示できる（GitHub Pagesは埋め込み拒否ヘッダなし）。
- GA・サーチコンソール・X・スプレッドシート・Shopify管理画面は相手側が埋め込みを拒否（X-Frame-Options: DENY / SAMEORIGIN、2026-09-11確認）。入れた場合は自動で新しいタブで開く（↗付き）。
- 最後に開いたページ・閉じたグループ・一覧をしまった状態は、そのブラウザだけに記憶（localStorage）。
- 左上の検索欄：ページ名・グループ名＋各ページのタイトル・見出し・本文で絞り込む（スペース区切りはAND、全角半角・大小文字は区別しない）。本文は検索欄を触った時に一覧のページを読み込んで探す。JSで後から描く中身（グラフ・データ）は探せない。
- `ページ一覧.js` は毎回 `?t=時刻` 付きで読む（GitHub Pagesのブラウザキャッシュ10分対策）。
- **トップ（最近の更新）**：左の一番上。開くとまずトップが出る。view全体の全HTMLを更新が新しい順に（直近2週間・ボタンで全件）。同じコミットでまとめて更新されたページは1行にまとめる（「ほか◯ページ」）。押すと右側で開く。
  - 仕組み：`.github/workflows/VIEW更新一覧.yml`（mainへのHTMLのpush時＋毎時10分）→ `更新一覧を作る.py` → **view-dataブランチ**の `更新一覧.json`（mainには置かない＝他の作業のpushを邪魔しない）→ VIEW管理が raw.githubusercontent.com から読む（最大5分ほど古いことがある）。
  - データだけ毎日入れ替わるダッシュボード（アクセス解析など）は、ページの近くの `data/` フォルダの更新も「更新」として拾う。
  - 除外：バックアップ（バックアップ・_旧・_bk）、書き出し用（export）、404、転送だけのページ、VIEW管理自身。
  - リポジトリが数GBあるので、Actionsはコミット履歴とHTMLだけ取り出す（blob:none＋sparse-checkout）。
