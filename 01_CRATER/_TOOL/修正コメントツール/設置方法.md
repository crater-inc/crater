# 修正コメントツール 設置方法（どのサイトでも1行）

## これ1行を `</body>` 直前に貼るだけ

```html
<script src="https://view.crater.co.jp/comment.js"></script>
```

これだけで、コメントピン機能（クラウド保存・PC/SP件数分離・修正済み管理）が丸ごと立ち上がる。
要素・CSS・Firebase SDK は comment.js が全部自前で用意するので、HTML側は**この1行だけ**。

## 設置場所（サイト種別ごと）

| サイト種別 | 貼る場所 |
|---|---|
| 静的HTML（view.crater.co.jp 配下） | 各HTMLの `</body>` 直前。相対 `<script src="/comment.js"></script>` でも可 |
| 静的HTML（別ドメイン） | 各HTMLの `</body>` 直前（上の絶対URL版） |
| **Shopify** | `theme.liquid` の `</body>` 直前 |
| **WordPress** | テーマの `footer.php` の `</body>` 直前（or フッター用カスタムHTML） |

## なぜどこでも動くか
- 外部依存は **Firebase SDK（www.gstatic.com）だけ**。相対リソース依存はゼロ。
- だから設置先のドメインを問わず、絶対URL 1行で完全動作する。
- コメントは Firestore（view-crater）にクラウド保存 ＝ **URLを共有するだけで別端末・クライアント・クロコと即共有**。

## 注意
1. **本番公開サイトに常時入れると一般訪問者にも 💬 ボタンが見える。** レビュー中だけ入れる／プレビュー環境／`?client=1`（クライアントモード）運用を推奨。
2. 設置先が**独自CSP**を敷いている場合のみ、以下を許可：
   - `script-src`: `https://view.crater.co.jp`
   - `connect-src`: `https://www.gstatic.com` `https://firestore.googleapis.com`
   - Shopify / WordPress の標準テーマは通常そのまま動く。
3. **唯一の正＝リポジトリ直下 `comment.js`。** ここを更新すれば絶対URL参照の全サイトが即・最新化。

## クロコに頼む場合
「◯◯にコメントツール入れて」と言えば、該当HTML/テーマの `</body>` 直前に1行入れて push → URL を返す。
