# CRATER 修正コメントツール ― 要件定義書

最終更新：2026-08-01 ／ 現行バージョン：**v1.0.0**

---

## 1. これは何か
テストアップ（確認用の実ページ）の上に、クライアントや社内が**ピンでコメント（修正指示）を直接置ける**ツール。Figmaの矢印注釈の代替。置かれたコメントは**クラウド（Firestore）に保存され、クロコがそのまま読み取って修正**する。

- **本体は1ファイル `comment.js`（リポジトリ直下）＝唯一の最新の正**。
- 各テストアップHTMLの `</body>` 直前に **`<script src="/comment.js"></script>` の1行だけ**で載る。
- **ここ（comment.js）を直せば、全案件が即・最新化される**（＝常に最新の1本を全案件で共有）。

## 2. 最大の要件（これが本質）
> **クライアントが修正を入れ「入れたよ」と伝えたら、クロコが全部・確実に読み取って直せること。**

→ 実現方法（実証済み・2026-08-01）：クロコはページURLからFirestoreを直接読む（下記 5.）。ブラウザも開かず、全文・場所・PC/SP・修正済フラグまで取得できる。

## 3. 運用スキーム（ケイスケ確定）
1. クライアントがテストアップにピンでコメント（＝**未対応**）。「入れたよ」＋URLをケイスケへ。
2. **クロコは未対応のコメントだけ読んで、全部直す。「修正済」カードは読まない＝終わったものとしてスルー。**
3. ケイスケが直りを確認 → OKなら **「修正済」を付ける（付けるのはケイスケ本人）**。
4. 修正済＝完了。クロコは以降そのカードを読まない。まだダメなら「戻す」で差し戻し。

## 4. 現行機能（v1.0.0）
- クラウド保存＋リアルタイム同期（Firestore `view-crater`）。別端末・クライアント・クロコで即共有。
- **1ページ＝1データ**。PC/SPは同じ場所に貯まり、ヘッダーに **「PC ○・SP ○」** で件数を分離表示（数字＝未対応の残数）。
- ピンは「今見ているビュー（PC/SP）」の分だけ表示。リストはPC/SP両方（各行にPC/SPタグ）。**ALL / PC / SP フィルタ**で絞れる。
- コメントを打つと、**どのセクション（要素名）＋近傍テキスト＋座標**を自動記録＝「どこの話か」が矢印なしで確定。
- **修正済フラグ**（付けるのはケイスケ）→「修正済みを隠す」で非表示。差し戻しは「戻す」。
- リスト行・ピン両方で**編集**（インライン）／削除。
- `?client=1` でクライアント公開モード。
- 💬ボタンはフラットデザイン（近黒円＋白ラインアイコン）。
- PC＝パネルを開くとコンテンツをパネル幅分だけ縮小して重ならない。SP＝ボトムシート（追加中はリストを畳んで下を触れる）。

## 5. クロコの読み取り経路（最重要）
URL（pathname）から PAGE_ID を計算し、Firestore REST を直接GET：

- `PAGE_ID = ("v" + pathname).replace(/[^a-zA-Z0-9_-]/g, "_")`
  - 例：`/CL/ESION/webpen/story.html` → `v_CL_ESION_webpen_story_html`
- `GET https://firestore.googleapis.com/v1/projects/view-crater/databases/(default)/documents/comments/{PAGE_ID}/items?key=<apiKey>`
- 取れる項目：`text / section / hint / name / view(PC/SP) / resolved / x,y / createdAt`
- **`resolved=false`（未対応）だけ拾う**。PC/SP両方が同じ場所に入っている。
- フォールバック：ページを（Playwright等で）開いて `window.__crComments` を読む＝同じ配列。

## 6. 技術構成
- 保存：Firebase / Firestore（プロジェクト `view-crater`）。構造 `comments/{PAGE_ID}/items/{id}`。
- 座標：`getRoot()` が表示中のzoomコンテナ（`#pageRoot`/`#pdpRoot`/`#spRoot`/`#storyRoot`/`#wf-overlay`）を自動判定→その中に%配置。zoom方式サイトでもズレない。
- PC/SP：コメントの `root`（コンテナid）と `view`（PC/SP）で区別。`view` は id に "sp" を含めばSP。
- SDK：firebase 8.10.1 を comment.js が自前で動的読み込み。
