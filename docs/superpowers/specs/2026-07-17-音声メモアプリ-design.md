# 音声メモアプリ（コードネーム：ボイスメモ）設計書

作成日：2026-07-17
用途：ケイスケさん個人用。出先でブラウザを開いてすぐ録音し、話した内容をほぼそのまま文字メモとして残す。内容をAIが感知して事前登録カテゴリーに自動振り分け。クラウド保存でPCからも見れる。

## 目的とゴール
- 開いた瞬間に録音を始められる（1タップ）。
- 録音内容は**要約せず**、話した言葉ほぼそのままテキスト化。
- 文字起こし内容をAIが判定し、**事前登録カテゴリーに自動でタグ付け**。該当なしは「未分類（インボックス）」。
- クラウド保存。iPhoneで録ったメモをPCのChromeでも見れる。
- **自分専用**。他人がURLを開いても自分のメモには入れない。ただし毎回パスワード入力はしたくない。

## 画面構成
1. **ホーム画面**：大きな「● 録音」ボタンと「メモを見る」ボタンのみ。
2. **録音画面**：録音ボタンを押す＝即キャプチャ開始 → リアルタイムで文字化を画面表示 → 停止で**新規メモとして自動保存** → AIタグ判定 → 保存完了。
3. **メモ一覧画面**：カテゴリー別に表示（未分類も1カテゴリ）。各メモは全文表示・編集・タグ手動変更・削除が可能。
4. **設定画面**：カテゴリー一覧の追加・編集・削除。

## 技術構成
- **文字起こし**：Chrome内蔵の音声認識（Web Speech API / SpeechRecognition）。無料・即動作・日本語対応。精度はそこそこで割り切る。
- **AIタグ付け**：Claude Haiku 4.5（Anthropic API）。文字起こしテキスト＋カテゴリー一覧を渡し「どのカテゴリーか、なければ未分類」を判定させる。
- **AI中継サーバー**：Cloudflare Workers（無料枠）。APIキーを隠すためのプロキシ。ブラウザ→Worker→Anthropic。キーはクライアントに出さない。
- **保存＆共有**：Firebase Firestore（無料枠 Spark）。メモ本文・タグ・日時を保存。端末をまたいで同期。
- **ログイン**：Firebase Authentication（Googleログイン）。**最初の1回だけ**ログイン、以降はブラウザがセッションを記憶＝毎回入力なし。Firestoreルールで自分のUIDのデータonly。他人がURLを開いても他人のメモは見えない。
- **ホスティング**：Firebase Hosting（無料枠）。`https://～.web.app`。iPhoneのホーム画面に追加してアプリ風に使える（PWA的）。

## データモデル（Firestore）
- `users/{uid}/memos/{memoId}`：`{ text, category, createdAt, updatedAt }`
- `users/{uid}/categories/{categoryId}`：`{ name, order }`

## AIタグ付けの流れ
1. 録音停止 → 文字起こしテキスト確定。
2. ブラウザが Cloudflare Worker に `{ text, categories: [名前...] }` を送信。
3. Worker が Anthropic API（Haiku）を呼び、「一覧のどれか / 該当なし」を返す。
4. ブラウザが結果を category として Firestore に保存。

## コスト
- Firebase：0円（無料枠）
- Cloudflare Workers：0円（無料枠）
- Claude Haiku：1メモあたり0.1円未満。月100メモでも十数円。初期にAnthropic残高 約$5（前払い）が必要な場合あり。
- 合計：実質ゼロ〜月数十円。

## デプロイ・運用
- Firebaseプロジェクト作成、Cloudflare Workerデプロイ、APIキー登録はすべてクロコ（Claude Code）が行う。ケイスケさんの作業はゼロ。
- APIキーは Worker の環境変数に保存。クライアントには一切出さない。

## スコープ外（YAGNI・今回はやらない）
- 音声ファイル自体の保存（テキストのみ保存。容量・コスト削減）。
- 要約・整文・翻訳。
- 長時間録音の高精度化（Whisper等）。将来必要なら差し替え検討。
- 複数ユーザー・共有機能。
- App Store 配信（今回は個人用Webアプリ。売る話は別途）。

## リスク・留意
- Web Speech API は Chrome前提。Safariは精度・安定性が落ちるためChrome推奨。
- 長時間の連続録音は途中で途切れる場合があるため、区切って録る運用を想定。
- 文字起こし精度は「そこそこ」割り切り。編集で直せる。
