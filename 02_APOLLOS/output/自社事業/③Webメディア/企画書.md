# APOLLOS Webメディア 企画書

## メディアコンセプト
**「認知マーケティングの教科書」**
中小企業・スタートアップが「選ばれる状態」を作るための実践情報メディア

## URL候補
- `media.apollos.jp`（サブドメイン）← 推奨
- `apollos.jp/media/`（サブディレクトリ）

## 収益の柱
1. **Google AdSense**（PV数に応じた広告収益）
2. **アフィリエイト**（マーケツール・SaaS紹介）
3. **APOLLOSへの問い合わせ獲得**（LTV最大の導線）

## アフィリエイト対象ツール候補
| ツール | 紹介報酬目安 |
|--------|-------------|
| BowNow | 要確認 |
| Buffer / Hootsuite | 月額の20〜30% |
| HubSpot | 数万円/成約 |
| Canva Pro | 月額の80% |
| Notion | プログラムあり |
| Semrush / Ahrefs | 月額の20〜40% |
