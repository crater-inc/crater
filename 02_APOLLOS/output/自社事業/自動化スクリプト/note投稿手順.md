# note.com 記事投稿 自動化手順

Playwrightを使ってクロコがブラウザ操作で投稿します。

## 使い方

「クロコ、noteにこの記事を投稿して」と言えばOK。
クロコがPlaywrightで以下を自動実行します。

## 投稿フロー

1. note.com にログイン（メール・パスワードが必要）
2. 新規記事作成ページを開く
3. タイトル・本文を入力
4. ハッシュタグを設定
5. マガジンに追加（「認知の教室 by APOLLOS」）
6. 公開設定を確認して投稿

## 事前に必要な情報

以下をクロコに教えてください（初回のみ）：

- noteのメールアドレス
- noteのパスワード
- マガジン名

※ パスワードはセッション中のみ使用。ファイルには保存しません。

## BOOTH 登録フロー

同様にPlaywrightで自動化できます：
1. BOOTH にログイン
2. 商品作成ページを開く
3. タイトル・説明文・価格・PDFをアップロード
4. 公開

## 投稿できる記事の形式

- Markdown形式（クロコが生成したもの）
- テキストをそのままコピー
