# 人と空間 実装メモ（HTML化のときに必ず読む）

## フッターの巨大シンボルマーク（円＋×＋四角）
- Pencil上：Footer内 `Giant Mark Mask`（クリップ枠）＋ `Giant Mark`（パス）。下側が見切れるクロップ演出。
- **コーディング仕様（ケイスケ指示 2026-07-23）：**
  - ブラウザの幅を広げても**縦横比率をキープしたまま**スケールさせる
  - ページの一番下で**画面幅いっぱい**に表示する（コンテンツ幅ではなくビューポート幅）
  - 下方向の見切れ（クロップ）は維持
- 実装の当たり：
  ```css
  .giant-mark{ width:100vw; overflow:hidden; }
  .giant-mark svg{ display:block; width:100%; height:auto; }
  /* 見切れ量はラッパーの max-height（vw比率）で調整。svgはviewBox必須（切り詰め済みのもの） */
  ```
  - SVGのviewBoxはマーク部分だけに切り詰める（Illustrator書き出しの余白に注意 → 全社ルール feedback_svg_viewbox）
  - 高さ固定(px)にしない。幅連動（vw）で比率キープ
